# UCMP

**Unofficial Cobblemon Patch** for **Cobblemon 1.7.3**.

UCMP is a small Fabric patch mod that fixes a few issues encountered with Cobblemon 1.7.3~

## Fixes

- Fixes visual desyncs when players ride Pokémon that were loaded late/off screen by other clients.
- Reduces server warn spam caused by Pokémon being discarded during entity tracking cleanup.
- Prevents some invalid Cobblemon shoulder effect data from being saved when disconnecting/reconnecting.

## Compatibility

This mod is made specifically for:

- **Minecraft 1.21.1**
- **Fabric**
- **Cobblemon 1.7.3**

Other Cobblemon versions and NeoForge are and will not supported.

## Installation

Install UCMP on both the **server** and **clients**.

## Modpacks

UCMP will not be published on Modrinth or CurseForge, but you can likely add it to a modpack as an external source.
